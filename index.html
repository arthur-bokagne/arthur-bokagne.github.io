Pipeline ETL automatisé

Un pipeline qui récupère des fichiers CSV, les nettoie et les normalise avec Pandas et NumPy, puis les charge dans une base PostgreSQL modélisée en MERISE/UML. Des requêtes SQL et des index servent ensuite à contrôler la qualité des données.

PythonPandasNumPyPostgreSQLSQLMERISE/UML
$ python pipeline_etl.py
[extract] lecture des fichiers CSV ✓
[clean] nettoyage, normalisation ✓
[transform] Pandas, NumPy ✓
[load] PostgreSQL, schéma 3NF ✓
[check] index + contrôles qualité ✓
→ 15 000+ lignes chargées
